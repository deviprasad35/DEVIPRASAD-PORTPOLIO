# Devi Prasad Biswal — Portfolio

Personal portfolio website built with React, Vite, and Tailwind CSS.

## Clone & run

```bash
git clone https://github.com/deviprasad35/DEVIPRASAD-PORTPOLIO.git
cd DEVIPRASAD-PORTPOLIO/client
npm install
npm run dev
```

## Build for production

```bash
npm run build
# Output → client/dist/
```

See `client/README.md` for full documentation.
